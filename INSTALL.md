# 安装 / Install

This is WNGjeanm's independent performance fork of bubble's Table Column Resizer.
Original copyright: Copyright (c) 2024 SOLO Builder. See the included MIT LICENSE
and THIRD_PARTY_NOTICES.md.

1. 在 Obsidian 设置中关闭 Table Column Resizer。
2. 备份 `.obsidian/plugins/table-column-resizer/` 文件夹。
3. 将安装包中 `table-column-resizer` 文件夹内的文件复制到该插件目录。
4. **保留已有 `data.json`**；不需要修改笔记。
5. 重新启用插件，在阅读视图中拖动表头右边缘。

Disable the existing plugin, back up its folder, replace the files in
`.obsidian/plugins/table-column-resizer/`, keep `data.json`, and re-enable it.
The plugin ID is retained for compatibility, so upstream and fork cannot run
side by side. To roll back, disable the plugin and restore the backup.

本分支与上游使用相同 ID，不能同时启用。请从本 Fork 更新；社区目录的上游更新可能
覆盖本分支。回退时关闭插件并恢复备份。
